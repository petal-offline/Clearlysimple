# ClearlySimple

ClearlySimple is Ayush Mishra's portfolio and a place to see the products and sites I ship.

I build mobile products and like working through the parts that only become obvious once people use them: product behavior, architecture, edge cases, debugging, releases, and iteration.

## Main product

[Petal Chan](https://petalchan.com/) is a privacy-first period and cycle tracker shipped on iOS and Android. It works offline without a required account and keeps sensitive information on-device.

The public engineering case study is here: [petal-chan-case-study](https://github.com/petal-offline/petal-chan-case-study).

## What this repo contains

- The ClearlySimple portfolio site
- Product pages and supporting UI components
- Small web experiences connected to the portfolio
- The source for a live Next.js site

## Stack

- Next.js and React
- TypeScript
- Tailwind CSS
- Framer Motion and GSAP for selected interactions

## Run locally

Requirements: Node.js and npm.

~~~bash
npm install
npm run dev
~~~

Open http://localhost:3000. To create a production build:

~~~bash
npm run build
~~~
